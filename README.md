# Next.js Boilerplate Project

This repository is a boilerplate project for quickly setting up a [Next.js](https://nextjs.org/) application with best practices and useful configurations pre-included.

## Features Included

- **TypeScript**: Fully configured TypeScript setup for type safety.
- **Linting and Formatting**: ESLint and Prettier configurations for consistent code quality.
- **State Management**: Integration-ready for Zustand. 
- **Styling**: Includes support Shadcn.
- **Environment Variables**: Built-in support for `.env` files.
- **Utilities**: Common utilities and helper functions.

## Getting Started

To get started with this boilerplate:

1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```

2. Install dependencies:
   ```bash
   npm install
   # or
yarn install
   # or
pnpm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   # or
   yarn dev
   # or
   pnpm dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.
